## Entry Points for Contributors

**Start anywhere. Fork freely. No permission needed.**

### Story Entry Points

- Write a chapter from the perspective of the house, La Ceniza, describing a memory it holds of a past love or death.
- Create an entry from *El Libro de los Hilos Rotos* for a minor character mentioned in passing (e.g., the tax assessor, Father Alonso).
- Write a letter from Soledad to Tomás, written before his disappearance, that foreshadows the novel's themes.
- Draft a folktale from the local jungle, told by a side character, that mirrors the central curse of the Sombra family.

### Technical Entry Points

- Build a 'Resonance Index' web tool that allows users to explore fictional entries from the *Book of Broken Threads* by emotional 'sound'.
- Create a visual generator that produces 'Gothic manuscript' images of text on skin-like parchment, using the novel's described script.
